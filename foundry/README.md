# Foundry

Cherry-picked Foundry artifacts, staged for `Hcalc/Foundry.lean`. Every
file carries an AGPL-3.0-only header. No Python anywhere in this tree.

## Layout

| Path | What it is |
| --- | --- |
| `c/beal_check.h`, `c/beal_check.c` | Bounded Beal-instance checker over u32 operands (general library, no main). `beal_check_u32(a, b, c, x, y, z)` returns `BEAL32_EQUAL` / `NOT_EQUAL` / `OVERFLOW` / `INVALID`. Checked mul/add/pow widened to 64 bits; fast paths for bases 0 and 1. |
| `c/beal_check_u32_test.c` | 35-check suite for the library. |
| `goldilocks/types.h` | Goldilocks constants: `GOLDILOCKS_PRIME`, `P_64` (first 64 primes), tiers, `StepInfo`, `AceCertificate`, witness/audit types. |
| `goldilocks/goldilocks.h`, `goldilocks/goldilocks.cpp` | Goldilocks field over p = 2^64 - 2^32 + 1: add/sub/mul/inv/pow, batch ops, `mulmod` via `__uint128_t` + Goldilocks folding. `add` uses a 128-bit sum, so it is correct for all canonical inputs including sums above 2^64. |
| `goldilocks/sha256.h`, `goldilocks/sha256.cpp` | SHA-256: portable C++ path plus the NASM fast path under `PMC_SHA256_NASM`. |
| `goldilocks/test_goldilocks.cpp` | 15-check harness for the C++ field. |
| `asm/sha256_nasm.asm` | NASM x86-64 SHA-256. Windows x64 ABI: `sha256_hash(RCX=data, RDX=len, R8=out)`. Linux callers use the SysV shim in `asm/shim_sysv.asm` (test-only). |
| `asm/test_sha256.c` | NIST vectors: empty, "abc", 56-byte, 1M x 'a'. |
| `wasm-agpl/` | Clean-room AGPL WebAssembly rewrite (see below). |

## wasm-agpl

Clean-room rewrite from mathematical definitions and test vectors. Zero
code carried over from any BSL-2.0 source. No browser shims. Module
layout, fixed linear memory offsets, and the result struct contract are
documented in `wasm-agpl/verifier/l2_l4_bridge.agpl.as`.

```
wasm-agpl/
  LICENSE                 AGPL-3.0-only module notice
  build.sh                Deterministic WASM build & vector runner
  goldilocks/field.agpl.as   add/sub/mul/pow/inv & reduction
  goldilocks/batch.agpl.as   batch ops & vector helpers
  hash/sha256.agpl.as        padding, schedule & compression
  verifier/banach_q.agpl.as  contraction ratio & q < 1 - epsilon gate
  verifier/sorry_audit.agpl.as  Lean sorry counter & proof status
  verifier/l2_l4_bridge.agpl.as L2/L4 entrypoints & linear memory ABI
  tests/                  vector suites (goldilocks, sha256, verifier)
  build/                  built .wasm (generated by build.sh)
```

Linear memory (one 64 KiB page): input at 0 (4096 bytes), scratch at 4096
(4096 bytes), result struct at 8192 (`+0` u32 status, `+8` u64 value,
`+16` u32 count). Status codes are returned, never thrown strings:
banach `0 = PASS, 1 = FAIL, 2 = INVALID`; proof
`0 = CLEAN, 1 = HAS_SORRY, 2 = HAS_ADMIT, 3 = NO_THEOREM, 4 = INVALID`.

## Build & test

```sh
# C library (35 checks)
gcc -std=c11 -Wall -Wextra -Werror -o /tmp/beal_u32_test \
  foundry/c/beal_check.c foundry/c/beal_check_u32_test.c
/tmp/beal_u32_test

# Goldilocks C++ (15 checks)
g++ -std=c++17 -Wall -Wextra -Werror -I foundry/goldilocks \
  foundry/goldilocks/goldilocks.cpp foundry/goldilocks/test_goldilocks.cpp \
  -o /tmp/test_goldilocks
/tmp/test_goldilocks

# NASM SHA-256 (4 vectors, via the SysV shim)
nasm -f elf64 foundry/asm/sha256_nasm.asm -o /tmp/sha256_nasm.o
nasm -f elf64 foundry/asm/shim_sysv.asm -o /tmp/shim.o
gcc -std=c11 -Wall -Wextra -Werror -o /tmp/test_sha256 \
  foundry/asm/test_sha256.c /tmp/shim.o /tmp/sha256_nasm.o
/tmp/test_sha256

# C++ SHA-256 portable path (3 vectors)
g++ -std=c++17 -Wall -Wextra -Werror -I foundry/goldilocks \
  foundry/goldilocks/sha256.cpp foundry/goldilocks/test_sha256.cpp \
  -o /tmp/test_sha256_cpp
/tmp/test_sha256_cpp

# WASM (33 + 9 + 25 checks, plus the bridge smoke check)
foundry/wasm-agpl/build.sh
```
